# Доказательства запуска и проверок

Здесь лежат артефакты, которыми подтверждается работа: скриншоты состояний,
записи экрана, вывод команд сборки и тестов.

Правило простое: утверждение «работает» без файла в этой папке или без вывода
команды в журнале доказательством не считается.

**Содержимое этой папки не удаляется и не перезаписывается** — см. запрет
в `AGENTS.md`, раздел «Что нельзя трогать». Удалённое доказательство
восстановить нечем: состояние устройства на момент съёмки уже не воспроизвести.

## Что здесь должно появиться

| Артефакт | Чем подтверждается |
|---|---|
| Вывод `./gradlew test` | Тесты ядра игры проходят |
| Вывод `./gradlew installDebug` | Проект собирается и ставится на устройство |
| Запись экрана 40–60 секунд | Партия переживает убийство процесса |
| Скриншоты семи состояний интерфейса | Состояния из `SPEC.md` достижимы руками |
| Скриншоты в тёмной теме | Тёмная тема не ломает читаемость |
| Скриншот при системном шрифте 200 % | Поле не разваливается |
| Запись партии в авиарежиме | Приложение работает без сети |
| Скриншот после порчи файла сохранения | Битые данные не роняют приложение |
