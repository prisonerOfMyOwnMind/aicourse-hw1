# Состояние проекта

**Обновлено:** 2026-08-17, сессия 1

## Готово

- Правила проекта: `AGENTS.md`, Часть II заполнена под задачу — стек с точными
  версиями, команды запуска, категоричные запреты, условия остановки, чек-лист
  перед финальным ответом
- `SPEC.md` написана до кода и прошла аудит двух независимых ревьюеров на Opus;
  43 находки разобраны с вердиктами, правки внесены
- Наивный прогон зафиксирован в `naive/` вместе с паспортом `NAIVE-RUN.md`:
  условия, промпт дословно, отчёт агента и проверенные факты вместо пересказа
- Ядро игры: правила, таймер, сериализация. Ни одного импорта `android.*`
- Хранилище: два файла, атомарная запись, независимое чтение, отказоустойчивый разбор
- 56 unit-тестов на JVM, все проходят
- UI: экран меню с рекордами и подтверждением потери партии, экран игры
  с полем, статусной строкой и оверлеем исхода, тёмная тема
- Приложение собрано и установлено на устройство, запускается, меню работает
- `README.md` переписан под проект, включая сравнение двух прогонов таблицей
- Плагины `superpowers` и `ponytail` в scope проекта, конфигурация в репозитории
- Репозиторий публичный, ссылка проверена без авторизации: HTTP 200

## В работе

Проверки на устройстве по `evidence/checklist.md`. Сняты: состояние 1 (меню без
сохранённой партии). Идёт запись экрана для сценария убийства процесса.

Автоматизация проверок невозможна: MIUI запрещает `input tap` и `pm clear`.
Ручные сценарии проходит владелец, агент снимает артефакты.

## Не начато

- Вибрация и анимация раскрытия волной. По спеке идут последними, после
  закрытия жизненного цикла и проверок. Вероятнее всего не войдут в сдачу
  и уйдут в README строкой «не сделано»
- Проверка на API 26: устройство одно, Android 13, эмулятор запрещён правилами

## Активные инструменты

Claude Code 2.1.233 с Opus 5, плагины `superpowers` 6.3.0 и `ponytail` 4.9.0
в scope проекта. JDK 21.0.11, Android SDK с platforms 36/36.1/37, adb 1.0.41.
Gradle 9.4.1, AGP 9.2.1, Kotlin 2.4.0, Compose BOM 2026.08.00.
Устройство: Xiaomi Redmi Note 10S, Android 13, API 33.

## Известные проблемы

- **Состояние 1 однажды показало кнопку «Продолжить»** на свежей установке.
  На диске действительно лежал файл партии `NOT_STARTED`; воспроизвести его
  появление без действий пользователя не удалось. Причина не найдена
- **`./gradlew installDebug` не работает на этом телефоне** из-за запрета MIUI
  на установку по USB. Обход: `adb install -r -t` тем же APK
- **minSdk 26 объявлен и не проверен ничем.** Приложение запускалось только
  на API 33
- **UI-тестов нет.** Проверка интерфейса ручная
- **Клетка меньше рекомендованной цели касания** на всех уровнях: 41,0 / 30,5 /
  22,6dp против 48dp. Сознательный компромисс, но на «Эксперте» промахи вероятны,
  и цена промаха — подрыв. Пальцем пока не проверено

поворот, тёмная тема, шрифт 200 %, узкий экран, авиарежим, порча обоих файлов

чек-листа фактом, а не ожиданием.
