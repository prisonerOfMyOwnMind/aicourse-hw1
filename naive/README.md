# Сапёр (Android)

Классический «Сапёр» под Android: Kotlin + Jetpack Compose, Material 3.

## Возможности

- Три уровня: Новичок 9×9 / 10 мин, Любитель 16×16 / 40, Профессионал 16×30 / 99.
- Первый ход всегда безопасен — мины расставляются после него, в обход клетки и её соседей.
- Лавинное раскрытие пустых областей.
- Флажки: долгое нажатие на клетку либо режим «Флажки» (кнопка внизу справа).
- «Аккорд»: тап по открытой цифре, вокруг которой уже стоит нужное число флажков,
  открывает остальных соседей.
- Счётчик мин, таймер, кнопка-смайлик для рестарта.
- После проигрыша видно, где были мины и какие флажки оказались ошибочными.
- Рекорд времени по каждому уровню сохраняется в `SharedPreferences` и показывается
  в меню выбора сложности.
- Тёмная тема, поворот экрана без потери партии, поле прокручивается на широких уровнях.

## Структура

```
app/src/main/java/com/example/minesweeper/
├── MainActivity.kt              точка входа
├── GameViewModel.kt             состояние партии, таймер, рекорды
├── game/
│   ├── Model.kt                 Cell, GameState, GameStatus, Difficulty
│   └── Minesweeper.kt           правила игры (чистые функции, без Android)
└── ui/
    ├── GameScreen.kt            шапка, счётчики, диалог итога
    ├── BoardView.kt             поле и клетка
    └── theme/                   тема и палитра поля
app/src/test/java/…/MinesweeperTest.kt   unit-тесты правил
```

Игровая логика полностью отделена от UI: `Minesweeper` — набор чистых функций
`состояние → состояние`, поэтому она проверяется обычными JVM-тестами без эмулятора.

## Сборка

Открыть папку проекта в Android Studio (Hedgehog или новее) и нажать Run.
Gradle-обёртка (`gradlew`, `gradle/wrapper/`) в комплект не входит — Android Studio
создаст её при первой синхронизации. Если собираете из терминала, сначала выполните
один раз:

```bash
gradle wrapper --gradle-version 8.7
./gradlew installDebug     # собрать и поставить на устройство
./gradlew test             # прогнать unit-тесты правил игры
```

Требуется JDK 17, Android SDK 34, minSdk 24.

## Правила, которые заложены в код

| Действие | Результат |
|---|---|
| Тап по закрытой клетке | открыть; мина → проигрыш |
| Тап по закрытой клетке в режиме «Флажки» | поставить/снять флажок |
| Долгое нажатие | поставить/снять флажок (в любом режиме) |
| Тап по открытой цифре | «аккорд», если флажков вокруг ровно столько, сколько показывает цифра |
| Все клетки без мин открыты | победа, оставшиеся мины помечаются флажками |

Таймер стартует с первого открытия клетки (не с первого флажка) и останавливается
в конце партии.
