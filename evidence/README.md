# Доказательства запуска и проверок

Правило простое: утверждение «работает» без файла в этой папке или без вывода
команды доказательством не считается.

**Содержимое этой папки не удаляется и не перезаписывается** — см. запрет
в `AGENTS.md`, раздел «Что нельзя трогать». Исключение сделано дважды и осознанно,
оба раза описаны ниже: удалён ложный артефакт и устаревший дубликат.

Построчный чек-лист с отметками — `checklist.md`.

## Чего здесь нет и почему

Эти сценарии требует задание, но артефактов по ним не появилось. В чек-листе
они помечены непроверенными.

| Сценарий | Почему нет |
|---|---|
| Системный шрифт 200 % | MIUI запрещает `settings put system font_scale` (`WRITE_SETTINGS`), руками владелец не проходил |
| Узкий экран | MIUI запрещает `wm size` (`WRITE_SECURE_SETTINGS`) |
| Прогон в авиарежиме | Не выполнялся. Косвенно закрыт отсутствием разрешения `INTERNET` в APK, но это не прогон |
| Режим «Don't keep activities» | Требует настроек разработчика, не проходился |
| Поворот в остальных состояниях | Снят только для «партия идёт» |
| Проверка на API 26 | Устройство одно, на нём API 33; эмулятор запрещён правилами проекта |

## Что было удалено из этой папки и почему

- **`09-menu-after-corrupt.png`** — снимок меню, сделанный в момент, когда порча
  файла ещё не удалась (`Permission denied`). Название обещало «после порчи»,
  а порчи не было: артефакт доказывал не то, что заявлял. Сама неудачная попытка
  сохранена в `corrupt-attempt-failed.log`.
- **`gradle-test-core.log`** — прогон тестов на промежуточном этапе, 42 теста.
  Устаревший дубликат: актуальный прогон на 56 тестов лежит в `gradle-test.log`.
