# Чек-лист ручной проверки на устройстве

Устройство: Xiaomi Redmi Note 10S (M2101K7BNY), Android 13, API 33, 1080x2400, density 440.

Заполняется по ходу проверки. Пустая отметка означает, что проверка не проводилась —
непроведённая проверка не считается пройденной.

| # | Сценарий | Ожидаемое | Факт | Артефакт |
|---|---|---|---|---|
| 1 | Установка на устройство | `./gradlew installDebug` завершается успехом | | |
| 2 | Первый запуск | Меню: три уровня, рекордов нет, «Продолжить» отсутствует | | |
| 3 | Начало партии | Все клетки закрыты, таймер 00:00, счётчик равен числу мин | | |
| 4 | Первый тап | Открывается область больше одной клетки, мины под тапом нет | | |
| 5 | Долгий тап | Ставится флажок, счётчик мин уменьшается | | |
| 6 | Короткий тап по флажку | Ничего не происходит, клетка не открывается | | |
| 7 | Перерасход флажков | Счётчик уходит в минус, вёрстка не ломается | | |
| 8 | Поражение | Мины раскрыты, подорванная выделена, неверные флажки перечёркнуты, оверлей с кнопками | | |
| 9 | Победа | Оставшиеся мины помечены флажками, счётчик 0, оверлей с временем | | |
| 10 | Рекорд | После победы в меню появляется лучшее время уровня | | |
| 11 | Убийство процесса | Ход, флажок, сворачивание, `adb shell am kill`, запуск — партия, флажки и время на месте | | |
| 12 | «Don't keep activities» | При включённой опции партия не теряется | | |
| 13 | Таймер в фоне | Скриншот времени, минута в фоне, возврат — прибавка близка к нулю | | |
| 14 | Поворот экрана | Во всех восьми состояниях вёрстка цела, партия не потеряна, прокрутки нет | | |
| 15 | Тёмная тема | Все состояния читаемы | | |
| 16 | Системный шрифт 200 % | Таймер, счётчик, кнопки, рекорды не обрезаны и не наезжают | | |
| 17 | Узкий экран | `adb shell wm size 720x1600` — поле помещается без прокрутки на всех уровнях | | |
| 18 | Авиарежим | Полная партия до победы при включённом авиарежиме | | |
| 19 | Испорченный файл партии | Приложение открывается без «Продолжить», рекорды на месте, падения нет | | |
| 20 | Испорченный файл рекордов | Блок рекордов пуст, «Продолжить» на месте | | |
| 21 | Системная «Назад» | На экране партии уводит в меню, партия сохранена | | |
| 22 | Подтверждение потери партии | Выбор уровня при живой партии показывает диалог | | |
